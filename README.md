# ResumePilot

ResumePilot 是一个本地优先的浏览器扩展，用来把求职资料填写到招聘网站的在线简历表单里。

它适合这样的场景：你已经有一份结构化资料或 PDF 简历，但不同招聘网站仍然要求反复填写姓名、联系方式、教育经历、实习经历、项目经历、证书、语言能力、意向城市等信息。ResumePilot 会读取当前页面结构，匹配字段和控件，再把本地资料写入页面。

数据默认留在当前浏览器。扩展不会自动投递，不会点击提交，也不会绕过登录、验证码或网站风控。

## 可以做什么

- 保存一份本地求职资料，覆盖基础信息、教育经历、工作/实习、项目、校园经历、奖项、证书、语言和家庭联系人。
- 从 PDF 简历提取文本，辅助生成资料。
- 保存简历附件，供后续招聘页面上传使用。
- 解析当前招聘页面的模块、字段、按钮、下拉框、日期面板、地区选择器和弹层。
- 将页面字段匹配到资料路径，例如 `educationExperiences[].schoolName`。
- 自动填写输入框、文本域、日期、年月、起止时间、下拉选择、搜索候选、单选、多选和部分地区组件。
- 对教育、实习、项目等重复经历区块，先补齐区块数量，再按资料顺序填写。
- 写入后检查页面实际值；不确定或不一致的结果会进入人工审核日志。
- 导出页面解析结果和填写日志，便于继续适配新的招聘系统。

## 不会做什么

- 不会自动提交简历或自动投递职位。
- 不会点击“下一步”“提交”“确认投递”等高风险按钮。
- 不会绕过验证码、登录、权限或网站风控。
- 不会把简历、资料或附件上传到远程服务器。
- 不保证覆盖所有招聘网站的所有自定义控件。

## 安装使用

### Chrome / Edge 本地加载

1. 下载 release 里的 zip。
2. 解压到本地目录。
3. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
4. 打开开发者模式。
5. 点击“加载已解压的扩展程序”，选择解压后的目录。
6. 点击浏览器右上角扩展图标，进入资料页编辑个人资料。

### 基本流程

1. 点击扩展图标，进入“编辑资料”。
2. 手动填写资料，或上传 PDF 简历尝试解析。
3. 可选：在资料页保存简历附件。
4. 打开招聘网站的简历填写页面。
5. 点击弹窗里的“解”，查看当前页面解析结果。
6. 点击“填写当前页面”，等待进度框结束。
7. 检查页面中标橙色或日志里提示人工确认的字段。

## 隐私与安全

- 个人资料文字保存在 `chrome.storage.local`。
- 简历附件保存在当前浏览器本地 IndexedDB。
- 扩展不会把你的简历、资料、附件上传到 GitHub 或任何服务器。
- 开源仓库不应该提交个人简历、导出的 profile、PDF、Word、日志或 release 压缩包。
- `.gitignore` 默认排除 `*.pdf`、`*.docx`、`*profile*.json`、`*resume*.json`、`*.log`、`dist/` 等敏感或构建产物。

## Release

0.0.1 发布两个浏览器包：

- Chrome: `resumepilot-chrome-v0.0.1.zip`
- Edge: `resumepilot-edge-v0.0.1.zip`

Chrome 和 Edge 目前使用同一套 Manifest V3 代码。两个包内容暂时一致，只是文件名区分浏览器；如果未来上架商店需要不同 manifest 或权限说明，再拆分专用构建。

本地打包：

```powershell
powershell -ExecutionPolicy Bypass -File tools/package-extension.ps1
```

脚本使用白名单复制源码文件，只会打包扩展运行需要的文件，不会包含测试样例、备份、临时目录、个人简历、导出资料或日志。

## 开发

这个扩展不需要构建前端框架，主要由 Manifest V3、content script、popup、profile page 和本地 JS 模块组成。

常用检查：

```powershell
node --check autofill.js
node --check content.js
node --check complex-controls.js
node --check popup.js
node --check profile.js
node --check resume-parser.mjs
node -e "JSON.parse(require('fs').readFileSync('manifest.json','utf8')); console.log('manifest ok')"
```
