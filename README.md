# ResumePilot - 自动填写简历机器人

ResumePilot 是一个完全开源的浏览器扩展，用来把本地求职资料自动填写到招聘网站的简历页面。它会先解析当前网页结构，识别字段、模块、按钮和动态选择控件，再按本地资料进行安全填写。

当前版本只在本地工作，不接入服务器，也暂未接入 AI。未来会考虑把 AI 作为兜底能力，用来处理未知页面、模糊字段和特殊交互，但不会让 AI 参与每一个普通字段填写。

## 项目亮点

- 本地资料库：基础信息、教育经历、工作/实习、项目、校园经历、奖项、证书、语言、家庭联系人等统一保存。
- PDF 简历解析：可以在资料页上传 PDF 简历，提取内容并辅助生成个人资料。
- 本地附件保存：可以保存简历附件，后续用于招聘页面的上传场景。
- 页面结构树：把当前网页抽象成布局区块、字段、按钮、导航、页头、页脚和弹层信息。
- 字段映射：把页面字段映射到统一资料路径，例如 `educationExperiences[].schoolName`。
- 重复经历处理：根据资料条数补齐教育、实习、项目等奖励/经历段数，再按顺序填写。
- 动态控件处理：支持一部分日期、年月、地区、搜索候选、固定下拉、单选/多选、排名区间等控件。
- 安全边界清晰：不会自动投递、删除、重置、跳转或点击下一步。
- 可审计：页面解析结果、填写结果和失败原因可以复制或下载日志，方便继续适配新网站。

## 能做什么

ResumePilot 适合处理招聘网站里常见的在线简历表单：

- 解析当前页面可以填写哪些字段。
- 识别字段属于哪个页面模块，例如个人信息、教育背景、实习经历、项目经历。
- 给字段匹配个人资料里的对应值。
- 自动填写普通输入框。
- 对可搜索候选列表执行“输入 -> 等待候选 -> 匹配 -> 选择”。
- 对封闭下拉执行“打开 -> 读取选项 -> 匹配 -> 选择”。
- 对年月、年月日、起止时间做结构化拆分和填写。
- 对地区类组件尝试省/市/区级联、搜索结果勾选和确认。
- 页面已有值默认跳过；强制覆盖时才会尝试重新写入并标记不一致结果。

它不适合也不会做这些事：

- 自动提交简历或自动投递职位。
- 绕过验证码、登录、权限或网站风控。
- 上传你的个人资料到服务器。
- 保证适配所有招聘网站的所有自定义控件。

## 安装使用

### Chrome / Edge 本地加载

1. 下载 release 里的 zip。
2. 解压到本地目录。
3. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
4. 打开开发者模式。
5. 点击“加载已解压的扩展程序”，选择解压后的目录。
6. 点击浏览器右上角扩展图标，进入资料页编辑个人资料。

### 基本流程

1. 点击扩展图标，进入“编辑资料”。
2. 手动填写资料，或上传 PDF 简历尝试解析。
3. 可选：在资料页保存简历附件。
4. 打开招聘网站的简历填写页面。
5. 点击弹窗里的“解”，查看当前页面解析结果。
6. 点击“填写当前页面”，等待进度框结束。
7. 检查页面中标橙色或日志里提示人工确认的字段。

## 隐私与安全

- 个人资料文字保存在 `chrome.storage.local`。
- 简历附件保存在当前浏览器本地 IndexedDB。
- 扩展不会把你的简历、资料、附件上传到 GitHub 或任何服务器。
- 开源仓库不应该提交个人简历、导出的 profile、PDF、Word、日志或 release 压缩包。
- `.gitignore` 已默认排除 `*.pdf`、`*.docx`、`*profile*.json`、`*resume*.json`、`*.log`、`dist/` 等敏感或构建产物。

## Release

当前计划发布两个包：

- Chrome: `dist/resumepilot-chrome-v0.0.1.zip`
- Edge: `dist/resumepilot-edge-v0.0.1.zip`

Chrome 和 Edge 目前使用同一套 Manifest V3 代码。两个包内容暂时一致，只是文件名区分浏览器；如果未来上架商店需要不同 manifest 或权限说明，再拆分专用构建。

本地打包：

```powershell
powershell -ExecutionPolicy Bypass -File tools/package-extension.ps1
```

脚本使用白名单复制源码文件，只会打包扩展运行需要的文件，不会包含测试样例、备份、临时目录、个人简历、导出资料或日志。

## 开发

这个扩展不需要构建前端框架，主要由 Manifest V3、content script、popup、options page 和本地 JS 模块组成。

常用检查：

```powershell
node --check autofill.js
node --check content.js
node --check complex-controls.js
node --check popup.js
node --check profile.js
node --check resume-parser.mjs
node -e "JSON.parse(require('fs').readFileSync('manifest.json','utf8')); console.log('manifest ok')"
```
